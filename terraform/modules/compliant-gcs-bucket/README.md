## This lab enforces the following NIST 800-53 R5 controls:  

**SC-12 (Cryptographic Key Establishment and Management):** Establish and manage cryptographic keys using automated methods and defined lifecycles whenever cryptography is employed within the system.  

**SC-13 (Cryptographic Protection):** Implement FIPS-validated? or NSA-approved cryptography to protect information in accordance with applicable laws and policies.  

**SC-28 (Protection of Information at Rest):** Protect the confidentiality and integrity of stored data—such as databases, disks, and object storage—using mechanisms like encryption.  

**AC-3 (Access Enforcement):** Enforce approved authorizations for logical access to information and system resources based on defined access control policies.  

**CM-6 (Configuration Settings):** Establish, document, and enforce mandatory security configuration settings for system components using hardened baselines.  

**AU-11 (Audit Record Retention):** Retain audit records for an organization-defined time period to support after-the-fact investigations and meet regulatory or policy requirements.
